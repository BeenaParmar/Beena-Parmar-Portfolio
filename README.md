# Beena Ashok Parmar - Portfolio

A responsive personal portfolio website showcasing projects, skills, education, and resume for Beena Ashok Parmar (IT Graduate & Aspiring Full Stack Developer).

## ✨ Features
- **Modern UI:** Built with Tailwind CSS and Phosphor Icons.
- **Interactive Resume Modal:** View HD resume preview directly on the site with download and full-size preview options.
- **Project Showcase:** Highlights major web development, software engineering, and database projects.
- **Multi-channel Contact:** Direct WhatsApp and Email integration.
- **Fully Responsive:** Optimized for mobile, tablet, and desktop screens.

## 📁 Repository Structure
- `index.html` / `Beena_parmar_portfolio.html` - Main portfolio webpage
- `Beena_Parmar_Resume_HD-1.png` - Resume preview image
- `Beena_Parmar_Resume_Final.pdf` - PDF copy of resume
